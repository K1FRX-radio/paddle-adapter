# Hardware

KiCad source for the custom paddle adapter PCB will live here.

Rev A is expected to include:

- USB-C receptacle
- USB ESD protection
- RP2040/RP2350-class MCU or equivalent
- required flash/power circuitry
- 3.5 mm TRS paddle input
- DIT/DAH input protection and optional RC filtering
- status LED
- SWD/programming access
- production test points

The schematic should be driven by the validated Rev 0 behavior rather than simply copying the KB2040 module.
